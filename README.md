# Bookstore Intelligence Scraper

Python web scraper built with requests, BeautifulSoup and pandas.
It scrapes title, price, rating, availability and product URL from
books.toscrape.com across multiple pages, converts star ratings to
numbers, saves the data to competitor_books.csv, and answers business
questions about pricing and ratings.

## How to run
Open the notebook in Google Colab and click Runtime > Run all.
